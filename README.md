# oil-and-gas
## Gas and Oil Pricing Calculator (Python)

This project simulates a gas and oil purchasing system with pricing rules,
bulk discounts, and province-based tax calculations.

### Features
- Gas and oil price calculation
- Bulk purchase discounts
- Province-based GST logic
- User input validation
- Formatted output

### Purpose
This project was created as part of coursework to practice Python control flow,
user input handling, and real-world business logic. AI tools were used for
guidance and debugging during development.
